# 💰 Salary Prediction System

## Overview

This project predicts employee salaries based on factors such as Age, Gender, Education Level, Job Title, and Years of Experience using Machine Learning.

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-Learn
* Streamlit

## Machine Learning Workflow

1. Data Cleaning
2. Duplicate Removal
3. Missing Value Handling
4. Label Encoding
5. Train-Test Split
6. Model Training
7. Model Evaluation
8. Streamlit Deployment

## Model Used

Random Forest Regressor

## Performance

* R² Score: 0.915
* RMSE: 12685

## Features

* Salary Prediction
* Dataset Preview
* Model Performance Display
* Interactive Streamlit Interface
